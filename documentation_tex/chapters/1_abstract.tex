\section{Introduction}
The traveling salesman problem is a popular entry problem for computational optimization using probabalistic methods.
It was first formulated in 1930 and is since than used as a benchmark for many optimization algorithms.
Even though the problem is computationally difficult, many heuristics and exact algorithms are known, which can approximate the exact solution within a small fraction of 1 \%.
This document focuses on implementing two different approaches to finding the optimal path and then comparing their runtime and uncertainties in their calculations.
First we focus on implementing a simple Metropolis algorithm with simulated annealing, where we compare different annealing strategies with the use of temperature functions.
In the second part of this document a genetic algorithm is implemented and at last compared to the probabalistic approach.
